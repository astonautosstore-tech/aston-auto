-- Admin function
create or replace function public.is_admin()
returns boolean as $$
begin
  return exists (
    select 1 from public.profiles
    where id = auth.uid() and role = 'admin'
  );
end;
$$ language plpgsql security definer;

-- Cars RLS
create policy "Public can view active cars" on public.cars for select using (true);
create policy "Admins can insert cars" on public.cars for insert with check (public.is_admin());
create policy "Admins can update cars" on public.cars for update using (public.is_admin());
create policy "Admins can delete cars" on public.cars for delete using (public.is_admin());

function getLocalStore<T>(key: string, defaultVal: T): T {
  if (typeof window === "undefined") return defaultVal;
  try {
    const raw = localStorage.getItem(key);
    return raw ? JSON.parse(raw) : defaultVal;
  } catch {

### How Local Fallback Works
- In `src/lib/supabase/client.ts`, `isSupabaseConfigured` tests:
  1. `process.env.NEXT_PUBLIC_SUPABASE_URL` exists
  2. `process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY` exists
  3. URL does not contain `"placeholder"`
  4. URL begins with `"https://"`
- If any check fails, `supabase` is instantiated as `null`.
- Every method in `storeApi` checks `if (isSupabaseConfigured && supabase)`. When false or when an API call errors, it immediately falls back to `getLocalStore()` and `setLocalStore()` which read and write to browser `localStorage` using keys:
  - `aston_cars_data_v1` (seeded with `SEED_CARS` from `src/lib/data/seed-cars.ts`)
  - `aston_orders_data_v1` (seeded with `[]`)
  - `aston_comments_data_v1` (seeded with `INITIAL_COMMENTS`)
  - `aston_settings_data_v1` (seeded with `INITIAL_SITE_SETTINGS`)
- This allows full CRUD testing (adding cars, placing test orders, approving reviews) even without a Supabase project connection.

### How Image Upload is Handled
- **No Supabase Storage bucket is currently used**:
  There is no `supabase.storage.from('cars').upload(...)` call anywhere in the code.
- In `AdminDashboardClient.tsx:944-945`, vehicle images (`hero_image`) are supplied via a standard text input field where the administrator pastes a direct image URL (e.g. Unsplash URL or external CDN URL).

### How the Admin Role is Determined
- In `supabase/migrations/001_initial_schema.sql:211-219`, the database defines a Postgres security definer function:
```sql
create or replace function public.is_admin()
returns boolean as $$
begin
  return exists (
    select 1 from public.profiles
    where id = auth.uid() and role = 'admin'
  );
end;
$$ language plpgsql security definer;
```
- This function checks `profiles.role = 'admin'` against `auth.uid()`.
- However, **in the TypeScript frontend, this check is never invoked or asserted** because no authentication session is requested.
